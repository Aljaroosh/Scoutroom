# Scoutroom

ScoutRoom är en scoutingplattform för fotboll där användare kan utforska spelare, klubbar och scoutingrapporter.


## Tech stack

### Backend

- Node.js
- TypeScript
- Express
- PostgreSQL
- Prisma ORM
